# Автотесты приложения «Свечи Мася»

Это проверяльщики. Они запускают расчёты приложения без человека и сверяют
результат с тем, каким он должен быть. Прогонять их надо **перед каждой
выкладкой на сайт**.

## Как запустить

Двойной клик по **«Проверить приложение.bat»** в папке проекта.
Откроется чёрное окно, через несколько секунд внизу будет написано либо
«VSE V PORYADKE», либо «EST OSHIBKI».

Если по-другому: `node tests/run-all.js` в папке проекта.
Отдельный тест: `node tests/test.js`.

Нужен Node.js. Если его нет — bat-файл сам скажет об этом и даст ссылку
(https://nodejs.org, кнопка LTS, установка с настройками по умолчанию).
Больше ничего ставить не надо: ни библиотек, ни браузера.

## Что означает результат

Каждая строка `ok` — одна сошедшаяся проверка. Строка `ОШИБКА` — разошедшаяся,
и рядом написано, что получилось и что должно было получиться.

- **всё сошлось** — версию можно выкладывать;
- **есть ошибки** — выкладывать нельзя, расчёт сломан;
- **НЕ ЗАПУСТИЛСЯ** — сломан сам файл или пропала метка (см. ниже).

## Как это устроено

Браузер не нужен. `harness.js` достаёт из `index.html` скрипт приложения,
обрезает его по метке `/* --- старт --- */` (всё, что ниже неё, — запуск
интерфейса) и выполняет остаток в Node с заглушками вместо браузера.
Дальше тесты дёргают функции приложения напрямую: `calc()`, `doBuy()`,
`doMake()`, `ledger()` и остальные.

**Одно требование к тому, кто правит `index.html`:** метка
`/* --- старт --- */` перед строкой `S=load()` должна остаться на месте.
Без неё тесты не запустятся — и честно об этом скажут, а не промолчат.

## Эталон себестоимости

`test.js` сравнивает себестоимость 71 изделия из примера с файлом `эталон.json`.
Смысл простой: приложение уже считает правильно, и эталон это фиксирует. Любая
случайная правка — забытая скобка в формуле, сдвинутая база процента — сместит
цифры, и тест назовёт поимённо каждое изделие, где стало иначе.

Если расчёт изменили **намеренно** и новые цифры верны, эталон надо обновить:

```
node tests/test.js --обновить
```

После этого посмотрите глазами несколько цифр и закоммитьте `эталон.json`
вместе с `index.html` — иначе следующий запуск снова будет ругаться.

Сверка с исходным Excel осталась, но печатается справочно и ошибкой не считается:
с 30.08.2026 расчёт разошёлся с файлом намеренно — в Excel масса воска округлялась
до десятков. Сейчас 64 изделия из 71 укладываются в 3 % от цифры файла; остальные —
известные ошибки самого Excel, они разобраны в `Отчёт-сверки.md`.

## Если тест ругается, а вы уверены, что всё правильно

Значит, поменялось само правило расчёта, а тест ждёт старое. Тогда правится
тест: в нём рядом с каждой цифрой написано, откуда она берётся. Менять
ожидаемое значение «чтобы стало зелёно», не разобравшись, — худшее, что можно
сделать: тест перестанет ловить настоящую поломку.
