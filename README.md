# Калькулятор себестоимости «Свечи Мася»

Расчёт себестоимости изделий ручной работы (свечи, гипсовый декор, ароматизация)
и учёт остатков материалов.

**Открыть приложение → https://rutasha2809-creator.github.io/svechi-masya/**


## Что внутри

- 481 материал в 21 справочнике: воск, фитили, отдушки, красители, гипс, пигменты,
  ёмкости, коробки, упаковка, формы, инструменты
- 71 изделие с полным составом: формовые, гипс-контейнер, стекло/металл,
  гипсовый декор, ароматизация, наборы
- Расчёт цены продажи по настраиваемому коэффициенту
- Приход материалов со средневзвешенной ценой закупки
- Списание материалов при выпуске партии
- Резервная копия базы в файл и загрузка обратно

## Как устроено

Одна самодостаточная HTML-страница: разметка, стили, скрипты и справочники —
всё в одном файле. Ни сервера, ни сборки, ни зависимостей.
Данные хранятся в браузере пользователя (localStorage) и никуда не передаются.

Файл можно скачать и открыть локально — интернет для работы не нужен.

## Как проверить перед выкладкой

В папке лежит файл **«Проверить приложение.bat»** — двойной клик, и все
расчёты прогоняются автотестами. Если внизу написано «VSE V PORYADKE» —
версию можно выкладывать. Подробнее: [tests/README.md](tests/README.md).

## Как обновить сайт

В папке проекта лежит файл **«Обновить сайт.bat»** — двойной клик, и свежая
версия уезжает на GitHub. Через минуту она открывается по ссылке выше.

Первый запуск заодно подключает папку к репозиторию и может попросить
войти в GitHub — дальше вход не потребуется.

Выкладываются только `index.html`, `README.md` и два документа. Рабочий Excel,
архивы и всё остальное из папки остаются только на компьютере — за это
отвечает файл `.gitignore`.
